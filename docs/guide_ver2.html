1이 도구는 무엇인가

사진은 형상 가설(어디에 구멍·슬롯·필렛이 있고 무엇이 대칭인가)의 근거일 뿐입니다. 모든 실제 치수는 여러분이 입력한 값에서 옵니다. 앱은 사진을 다시 보지 않습니다.

사진 → topology, 면, 구멍·슬롯, 축, 대칭, 반복 패턴, 기준면 후보 (구조만)

여러분의 입력 → 모든 길이·직경·반경·깊이·각도·위치 (유일한 치수 근거)

사진› 구조 관찰› 실측 요청› 여러분의 실측› 검증된 사실› CAD 피처› .ipt

이 도구가 절대 하지 않는 것  사진 → 치수 추측 → .ipt

2받은 것 · 필요한 것

여러분이 받은 것

  • Photo-to-IPT Builder 폴더 — 앱 본체(Photo-to-IPT Builder.exe + _internal/ + licenses/). 압축을 풀어 그대로 실행합니다. 설치 관리자 없음.
  • input/<부품이름>/ 폴더 — 사진 분석 담당자가 Claude Code로 만들어 전달한 것. 안에 measurement-request.json(또는 measurement-input.json)과 feature-intent.json이 들어 있습니다. 이 두 파일이 없으면 앱이 빌드를 막습니다.

PC 요건

  • Windows 10 또는 11 (64-bit)
  • Autodesk Inventor 2027 이 설치되어 있을 것 — 앱은 Inventor를 COM으로 구동합니다. 경로는 실행 시 레지스트리에서 자동으로 찾습니다.
  • Python·PowerShell 7·인터넷·Autodesk 로그인 — 불필요.

사진 분석은 이 앱이 하지 않습니다. 부품 사진 → 구조 → input/<part>/ 폴더 생성은 Claude Code에서 /inventor-photo-to-ipt 스킬로 1회 수행하고, 그 폴더만 이 앱으로 반복 사용합니다. (§9 · §11 참고)

3설치 & 첫 실행

  1. 폴더 압축 해제

    Photo-to-IPT Builder.zip 을 원하는 위치(바탕화면, C:\Tools\ 등)에 풉니다. 경로에 한글·공백이 있어도 됩니다. 네트워크 드라이브보다 로컬 디스크를 권장합니다.

  2. 차단 해제 (서명 없는 빌드)

    개인/연구용이라 코드 서명이 없습니다. 처음 한 번만 해제하면 됩니다 — 두 방법 중 택1:

    방법 A · 폴더 전체 차단 해제 (권장, 경고가 아예 안 뜸) — 압축 푼 위치에서 PowerShell 한 줄:

    Get-ChildItem -Recurse "C:\Tools\Photo-to-IPT Builder" | Unblock-File

    방법 B · 실행 시 클릭 — Photo-to-IPT Builder.exe 더블클릭 → “Windows의 PC 보호” 창에서 “추가 정보” → “실행”. 같은 파일은 한 번만 묻습니다.

    압축 파일에서 바로 실행하지 말고 먼저 폴더로 압축 해제하세요. zip → 우클릭 → 속성 → “차단 해제” 체크 → 압축 해제 를 먼저 하면 방법 A도 생략됩니다. 폴더 안 READ ME FIRST.txt 에 같은 안내가 들어 있습니다.

  3. 환경 칩 확인

    창 우측 상단 칩이 Inventor 2027 감지됨(녹색)이면 준비 완료입니다. Inventor 미감지(빨강)이면 §7 문제 해결을 보세요.

  4. (선택) 무결성 자체 점검

    창을 열지 않고 앱이 제대로 동작하는지 한 줄로 확인합니다. 명령 프롬프트에서:

    "Photo-to-IPT Builder.exe" --selftest         # import·번들·검증·플랜 점검  →  SELFTEST: PASS
"Photo-to-IPT Builder.exe" --selftest-build   # 위 + Inventor 빌드까지 실제 수행

    SELFTEST: PASS 가 나오면 배포본이 정상입니다. GUI가 오류를 다이얼로그 뒤에 숨기는 패키징 문제까지 잡아냅니다.

4사용 방법 (단계별)

한 번 사진 분석이 끝난 input/<part>/ 폴더가 있으면, 아래를 반복합니다. 치수를 바꿔 다시 빌드하는 루프가 이 앱의 핵심 용도입니다.

  1. 작업 폴더 선택

    상단 작업 폴더 선택… 버튼 → 받은 …/input/<부품이름>/ 폴더를 고릅니다. 측정 테이블이 채워지고, 우측 피처 인텐트 도크에 만들어질 피처 목록(예: F001 base_extrude / F002 hole / F003 fillet)이 보입니다. 상단에 부품 이름과 결과가 저장될 output/<부품이름>/ 경로가 표시됩니다.

  2. 측정값 입력

    테이블에서 “값” 열만 편집합니다(더블클릭). 각 행의 이름·측정 방법·단위를 참고해 캘리퍼스 등으로 잰 숫자를 넣습니다. 단위는 바꾸지 않습니다. 측정 요령은 §5 를 보세요.

  3. 검증

    스키마 + 지오메트리 규칙을 검사합니다. 통과하면 상태줄에 검증 통과, 로그에 MEASUREMENT_VALIDATION_OK. 실패하면 문제가 있는 행이 빨갛게 표시되고 로그에 ID별 사유가 나옵니다 — 값을 고치고 다시 검증.

  4. 플랜 생성

    검증을 통과하고 feature-intent.json 이 있으면 활성화됩니다. 결정적 cad-plan.json + 사람이 읽는 cad-plan.md 를 output/<부품이름>/ 에 씁니다. 로그에 피처 순서와 파라미터 맵이 표시됩니다.

  5. Inventor 빌드

    플랜이 있고 환경 칩이 녹색이면 활성화됩니다. Inventor 2027이 없으면 자동 실행되고 (첫 실행은 1~3분 걸릴 수 있음), 로그에 [INFO] F001 … 처럼 진행이 흐릅니다. 진행바가 도는 동안 창은 계속 반응합니다. 필요하면 취소 로 중단 (실행된 Inventor도 함께 종료).

  6. 결과 확인

    성공 시 상태줄에 BUILD PASS — … 1 body, N features. .ipt 열기 로 Inventor에서 모델을 열고, 리포트 열기 로 build-report.md(PASS/FAIL · 파라미터 맵 · Inventor 결과)를 봅니다. 자세한 로그는 같은 폴더의 build-log.txt.

  7. 치수를 바꿔 재빌드

    테이블에서 값을 수정 → 검증 → 플랜 생성 → Inventor 빌드. output/<부품이름>/ 의 이전 산출물은 덮어써집니다.

feature-intent.json 이 없으면 우측 도크에 “Claude Code에서 … /inventor-photo-to-ipt … 먼저 실행” 안내가 뜨고 플랜 생성·Inventor 빌드 가 비활성화됩니다. 사진 분석 담당자에게 그 폴더를 다시 만들어 달라고 요청하세요.

5측정값 입력 요령

여러분이 편집하는 건 “값” 열 숫자뿐 입니다. 한 항목 = 한 물리량. 아래 도구·방법을 지키면 검증을 바로 통과합니다.

측정 대상도구방법
전체 폭 / 높이 / 두께캘리퍼스최대 스팬. 두께는 필렛을 피해서 잰다.
구멍 직경캘리퍼스(내측 조)구멍 자체(끼우는 볼트가 아님). 관통/막힘 여부를 담당자에게 알린다.
막힌 구멍 깊이뎁스 게이지직경과 별도 항목으로 잰다.
구멍 위치캘리퍼스선언된 원점 또는 지정된 모서리 기준. 구멍 쌍은 중심–중심.
모서리 / 에지 반경R 게이지호에 맞는 반경.
챔퍼캘리퍼스 + 각도기다리 길이(45°가 아니면 각도도).
각도각도기지정된 두 면 사이.
패턴 간격 / 피치캘리퍼스인접 인스턴스 중심–중심.
패턴 개수—정수, 1 이상.

검증이 막는 것

  • 필수 값이 비어 있음 / 유한한 숫자가 아님. 길이·두께·깊이·직경·반경은 > 0 (위치는 0 가능, 음수 불가).
  • 단위/타입 불일치 — length ↔ mm·cm·in, angle ↔ deg, count ↔ count.
  • 구멍 직경 ≥ 그 구멍이 놓인 면의 최소 스팬.
  • 구멍 중심 ± 반경이 몸체 바깥으로 나감.
  • 필렛/챔퍼 크기 ≥ 최소 면 스팬의 절반 (기하학적으로 불가능).
  • 패턴 개수가 정수 1 미만, 원형 패턴 총 각도가 (0, 360] 범위 밖.
  • 측정 ID 중복, 또는 related_visual_feature 가 이미지 분석 ID와 안 맞음.

실패하면 MEASUREMENT_VALIDATION_FAILED 와 함께 문제 ID별 한 줄 사유가 나옵니다. 해당 값만 고쳐 다시 검증. 통과 전에는 아무것도 빌드되지 않습니다.

6결과 읽기 — PASS / FAIL

아래를 모두 만족하고 build-report.md 에 기록될 때만 PASS 입니다. 파일 없음·0바이트·바디 없음·Update 오류는 FAIL.

  • 스키마 검증 통과
  • 지오메트리 일관성 검증 통과
  • cad-plan.json 스키마 + 참조 검증 통과 (피처 DAG, 결합된 파라미터)
  • Inventor 2027 연결 — SoftwareVersion major = 31
  • 모든 계획 피처 생성 + Update() 미해결 오류 0
  • output/<부품이름>/<부품이름>.ipt 파일이 디스크에 존재, 확장자 .ipt, 크기 > 0
  • 재오픈 시 문서 유형 kPartDocumentObject, 솔리드 바디 ≥ 1
  • 재오픈 피처 수가 계획과 일치, 상태 이상 피처 없음

산출물 파일 (부품별)

<작업폴더>/output/<부품이름>/
  validation-report.json   # 스키마 + 지오메트리 검증 결과
  cad-plan.json            # 결정적 피처 플랜
  cad-plan.md              # 사람이 읽는 피처 순서 + 파라미터 맵
  <부품이름>.ipt            # 모델 — Inventor에서 열기
  build-log.txt            # 단계별 [INFO]/[WARN]/[ERROR] 로그, 예외 원문
  build-report.md          # PASS/FAIL · 파라미터 맵(M-ID → p_이름 → 치수 → 피처) · Inventor 결과

7문제 해결

증상원인조치
환경 칩이 “Inventor 미감지” (빨강) Inventor 2027 미설치 / COM 미등록 / 다른 버전 Inventor 2027 설치. 이미 설치했다면 Inventor를 한 번 실행해 등록. 명령줄에서 "Photo-to-IPT Builder.exe" --selftest 실행 후 note 확인.
exe가 안 열림 — “Windows의 PC 보호” SmartScreen (서명 없는 개인/연구용 빌드) “추가 정보” → “실행” (파일당 1회). 또는 압축 푼 폴더에서 Get-ChildItem -Recurse "<폴더>" | Unblock-File 실행 → 경고 자체가 사라짐. (§3 · READ ME FIRST.txt)
백신이 exe를 격리 / 삭제 서명 없는 PyInstaller 번들 오탐 예외(허용) 등록, 또는 서명본 요청. --selftest 로 무결성 확인 가능.
폴더를 열었더니 “measurement 파일이 없습니다” 부품 폴더가 아님 …/input/<부품이름>/ 폴더를 선택. 그 안에 measurement-input.json(또는 -request)와 feature-intent.json이 있어야 함.
우측 도크에 “Claude Code에서 … 먼저 실행” feature-intent.json 없음 사진 분석(Phase A~C)을 담당자가 Claude Code로 수행해 폴더를 다시 전달.
검증 실패, 행이 빨감 측정값이 스키마/지오메트리 규칙 위반 로그의 MEASUREMENT_VALIDATION_FAILED 아래 ID별 사유 확인 → 값 수정 → 다시 검증. (§5)
빌드 FAIL, BLOCKED: … Inventor COM 연결 실패 / 파트 템플릿 없음 / 리빌드 오류 build-log.txt 의 [ERROR] 줄 확인. Inventor를 수동으로 한 번 실행한 뒤 재시도.
빌드가 멈춘 것처럼 보임 Inventor 최초 기동이 느림 (1~3분) 기다린다. 진행바가 돌면 정상. 정말 멈췄으면 취소 → 재시도.
빌드는 됐는데 .ipt가 안 보임 다른 output 위치를 보고 있음 상단에 표시된 <작업폴더>/output/<부품이름>/ 를 확인. .ipt 열기 버튼 사용.
(CLI) “pwsh 7에서 실행하지 마세요” 류 메시지 PowerShell 7(pwsh)로 .ps1 실행 powershell.exe (Windows PowerShell 5.1)로 실행. GUI 앱은 자동으로 올바른 셸을 씀.

9내부에서 무슨 일이 일어나는가

전체 파이프라인은 아래 9단계입니다. GUI 앱은 Phase E~I(5~9)만 담당하고, Phase A~D(사진 → 구조 → 실측 요청)는 Claude Code에서 1회 수행합니다. 역할 — 사용자 Claude 시스템 Inventor

  1. Phase A이미지 입력사용자

    부품 사진(전/후/좌/우/상)을 Claude Code 채팅에 첨부하고 이 부품을 Inventor 2027 .ipt로 만들어줘 라고 요청. Inventor는 실행 안 함.

  2. Phase B구조 분석Claude

    이미지에서 구조만 추출 — 부품 유형, 보이는 면, 원·구멍·슬롯, 축, 대칭, 반복 패턴, 기준면 후보, 가림/모호 영역, 신뢰도. 시각 피처에 ID 부여. mm·도 값은 산출 안 함.

  3. Phase C실측 요청 생성Claude

    input/<part>/measurement-request.json(모든 값 null) + feature-intent.json(파라미터↔측정 ID, 스케치 평면, 피처 순서) 작성.

  4. Phase D실측값 입력사용자

    부품을 실제로 측정해 각 null을 숫자로 교체 → input/<part>/measurement-input.json. ← 이 앱의 “측정값 입력” 단계.

  5. Phase E검증 (하드 게이트)시스템

    스키마 → 지오메트리 일관성. 실패 시 문제 ID를 반환하고 중단. 통과 전 Inventor 실행 없음.

  6. Phase F피처 플랜시스템

    결정적 cad-plan.json 생성 — 파라미터가 measurement ID에 연결, 피처 위상 정렬, provenance(sha256) 기록. 미지원 피처와 결합되지 않은 치수는 거부.

  7. Phase GInventor 빌드Inventor

    Inventor 2027 연결(없으면 실행), p_<이름> 사용자 파라미터를 단위 표현식으로 생성, 스케치·치수 구속·피처를 순서대로 생성, Document.Update() → .ipt 저장. Windows PowerShell 5.1(STA)에서 수행.

  8. Phase H검증시스템

    .ipt를 다시 열어 확인 — 파일 존재, 크기 > 0, kPartDocumentObject, 솔리드 바디 ≥ 1, 피처 수, 상태 오류 없음. Result: PASS 일 때만 성공.

  9. Phase I리포트시스템

    build-report.md(입력·provenance, 검증, 파라미터 맵, 피처, Inventor 결과, PASS/FAIL) + build-log.txt 생성.

GUI .exe 빌드

pip install -r requirements-dev.txt      # pyside6 + pyinstaller (빌드 PC만)
powershell -File build/build.ps1         # --onedir (권장)  →  build/dist/Photo-to-IPT Builder/  (~115 MB)
powershell -File build/build.ps1 -OneFile   # 단일 .exe (더 큼, 백신 오탐 ↑)
  • 배포 단위 — build/dist/Photo-to-IPT Builder/ 폴더 전체를 zip으로. --onefile 은 매 실행 시 %TEMP% 에 재추출하고 SmartScreen을 더 건드립니다.
  • 대상 PC — Inventor 2027 필수. Python·pwsh 7·인터넷 불필요. Inventor 경로는 레지스트리(Inventor.Application ProgID)에서 런타임에 해석.
  • 무결성 확인 — 배포 후 대상 PC에서 "Photo-to-IPT Builder.exe" --selftest → SELFTEST: PASS.
  • 라이선스 — build.ps1 이 THIRD-PARTY-NOTICES.txt + licenses/ (PySide6/Qt 는 LGPL-3.0)를 dist에 씁니다. 외부 배포 전 build/licenses/LGPL-3.0.txt (gnu.org)를 넣어두면 자동 포함됩니다.
  • 아이콘 — build/app.ico 는 python build/make_icon.py 로 재생성. 빌드가 자동 적용(exe 아이콘 + 창 아이콘).
  • 서명(선택, 인증서 필요) — SmartScreen 프롬프트를 줄이려면: powershell -File build/sign.ps1 -Pfx <cert.pfx> -Password <pw> (또는 -Thumbprint). 인증서는 프로젝트에 포함되지 않습니다.
  • CI — powershell -File ci/run_ci.ps1 (테스트 + GUI 스모크 + 빌드 + --selftest). .github/workflows/ci.yml 가 windows-latest 에서 실행. Inventor E2E 는 tests/run_ps_tests.ps1 로 수동.
