Photo-to-IPT Builder  —  먼저 읽어주세요 / READ ME FIRST
========================================================

이 앱은 코드 서명이 되어 있지 않습니다(개인/연구용 빌드).
처음 실행할 때 Windows가 한 번 경고를 보여줍니다. 아래 중 하나로 해제하세요.


[방법 A — 폴더 전체 차단 해제 : 권장, 경고가 아예 안 뜸]

  압축을 푼 위치에서 PowerShell을 열고 한 줄 실행:

      Get-ChildItem -Recurse "<이 폴더 경로>" | Unblock-File

  예:
      Get-ChildItem -Recurse "C:\Tools\Photo-to-IPT Builder" | Unblock-File


[방법 B — 실행할 때 클릭]

  "Photo-to-IPT Builder.exe" 더블클릭
    → "Windows의 PC 보호" 창이 뜨면
    → "추가 정보" 클릭
    → "실행" 버튼 클릭

  같은 파일은 한 번만 물어봅니다.


[팁] zip을 풀기 전에  우클릭 → 속성 → "차단 해제" 체크 → 압축 해제  하면
     방법 A/B 둘 다 필요 없습니다.


[정상 동작 확인 — 창 없이]

  명령 프롬프트에서:

      "Photo-to-IPT Builder.exe" --selftest

  →  SELFTEST: PASS  가 나오면 배포본이 정상입니다.


요건: 이 PC에 Autodesk Inventor 2027 이 설치되어 있어야 합니다.
자세한 사용법은 함께 받은 사용 설명서(guide_ver2.html)를 참고하세요.
